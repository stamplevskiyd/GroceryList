# ADR-0000. Фиксируем архитектурные решения в ADR

Статус: принято · Дата: 2026-09-29

## Контекст

Код пишется в том числе ассистентами, которые не помнят прошлых обсуждений. Решения вида «как мы
работаем с сессией БД» или «где живёт бизнес-логика» должны быть записаны там, где их прочитает
любой, кто пишет код, — иначе каждый новый модуль изобретает свой подход.

Спецификация (`docs/superpowers/specs/`) отвечает на вопрос «что делает система». ADR отвечают на
вопрос «как устроен код и почему».

## Решение

- ADR лежат в `docs/adr/`, имя файла — `NNNN-kebab-case.md`, номера идут подряд и не переиспользуются.
- Язык — русский. Шаблон — ниже. Спецификацию не пересказываем, ссылаемся на её разделы (`спец. §5.3`).
- Статусы: **предложено** → **принято** → (**заменено ADR-NNNN** | **отменено**).
- Принятый ADR не переписывается по существу. Если решение меняется — пишется новый ADR,
  у старого меняется только статус. Опечатки и уточнения формулировок править можно.
- Новый ADR нужен, когда решение: влияет на несколько модулей, задаёт правило, которое легко
  нарушить незаметно, или выбирает между разумными альтернативами.
- Каждый ADR содержит раздел «Как проверяется»: тест, правило линтера или пункт ревью, по которому
  видно нарушение. Решение без проверки со временем перестаёт соблюдаться.
- `docs/adr/README.md` — оглавление; новый ADR добавляется туда в том же коммите.

## Шаблон

```markdown
# ADR-NNNN. Заголовок-решение

Статус: предложено · Дата: ГГГГ-ММ-ДД

## Контекст
Какая проблема, какие силы и ограничения.

## Решение
Что делаем. Конкретно, с именами модулей и примерами кода, если они снимают неоднозначность.

## Последствия
Что становится проще, что сложнее, что это значит для пишущего код.

## Как проверяется
Тест / линтер / пункт ревью.
```

## Последствия

- Перед работой над модулем читаются ADR из оглавления — это часть контекста наравне со спекой.
- Небольшая стоимость: изменение правил требует нового файла, а не правки старого.

## Как проверяется

Ревью: PR, меняющий правило из принятого ADR, без нового ADR — не принимается.
