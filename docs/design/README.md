# Дизайн GroceryList PWA

Макет сделан в Claude Design: https://claude.ai/artifact/FMbESzKABq3jNjcSH9Tqq5
(приватный; актуальная версия — там, здесь снимок на момент коммита).

- `tokens.css` — цвета, шрифты, радиусы для светлой и тёмной темы. Подключать в приложении как есть.
- `screens/*.dc.html` — экраны. Это эталон разметки, размеров и поведения, а не готовые компоненты:
  стили заданы inline через те же CSS-переменные, логика — в `<script type="text/x-dc">` внизу файла.
  `{{…}}`, `<sc-if>`, `<sc-for>` — шаблонный синтаксис редактора, в React они становятся
  условиями и `map`.
- `screens/canvas.json` — раскладка холста (служебный файл редактора).

Шрифты: Literata (заголовки) и Onest (интерфейс), Google Fonts, кириллица.
Экраны нарисованы под iPhone 390×844; на десктопе — та же раскладка, шире.

## Что осталось заполнить

- `[логин]` на экранах входа, согласия и настроек — подставляется из `GET /api/me`.
- Инструкция для Codex CLI в настройках — `[ИНСТРУКЦИЯ ДЛЯ CODEX]`.
- Шаги подключения для claude.ai и ChatGPT написаны общими словами — сверить с их текущим интерфейсом.
