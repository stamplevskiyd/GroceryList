# Этап 7 — первый рабочий интерфейс

2026-10-04 владелец выбрал настоящий список поверх готового API, чтобы уже сейчас
проверить поведение в браузере. Это минимальная часть этапа 7, не весь PWA.

## Реализовано

- React, openapi-fetch и openapi-react-query / TanStack Query по ADR-0009.
  Контракт берётся из сгенерированного OpenAPI, cookie не доступны JavaScript.
- Вход, выход с очисткой кэша, выбор доступного списка.
- Быстрый ввод: строка передаётся серверу, включая разбор количества и объединение.
- Отметка купленного и возврат, удаление с подтверждением, очистка всего купленного.
- Фильтр по нескольким тегам; новая позиция получает выбранные теги.
- Количество, единицы, заметки и источник MCP отображаются в строке.
- SSE инвалидирует запрос списка; после восстановления соединения список загружается
  заново. Есть ручное обновление и сообщения об ошибках. Неуспешный ввод не стирается.
- Адаптивная светлая/тёмная тема на дизайн-токенах существующих макетов.
- Экран OAuth переведён на общий типизированный клиент.

Витест/DOM-проверки: вход → добавление → купленное → выход, сохранение ввода при ошибке,
SSE и безопасное текстовое отображение имени. Включены в `scripts/check.sh`.
Это проверки логики; визуальная браузерная приёмка остаётся за владельцем.

## Ручная приёмка

Открыть https://grocery.94-159-101-162.sslip.io после публикации `v0.2.0`:

1. Войти; добавить `молоко 2 л`, убедиться в количестве и единице.
2. Обновить страницу — позиция сохраняется на сервере.
3. Открыть вторую вкладку. В первой отметить покупку; во второй она переходит в купленное.
4. Раскрыть «Куплено», вернуть позицию в покупки, удалить её с подтверждением.
5. Выйти: список исчезает, показана форма входа.

Для localhost `npm run dev --prefix frontend` проксирует API на `localhost:8000`.
Полноценный cookie-вход в Safari проверяется по HTTPS. Сертификаты ОС не меняются.
