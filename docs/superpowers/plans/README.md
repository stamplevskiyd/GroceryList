# Планы реализации GroceryList v1

Спека: [`../specs/2026-09-29-grocery-list-design.md`](../specs/2026-09-29-grocery-list-design.md).
Правила кода: [`../../adr/README.md`](../../adr/README.md).

Реализация разбита на последовательные планы. Каждый план заканчивается работающим и проверенным
результатом (`scripts/check.sh` зелёный), следующий пишется после завершения предыдущего — с учётом
того, что выяснилось по ходу.

| № | План | Результат | Статус |
|---|---|---|---|
| 1 | [Фундамент бэкенда](2026-09-29-01-backend-foundation.md) | Проект, инструменты и проверки, настройки, `unit_of_work`, базовый репозиторий, миграции, тестовая инфраструктура, `/api/health`, CI | выполнен |
| 2 | [Домен списка покупок](2026-09-30-02-shopping-domain.md) | Модели списков, позиций, тегов, событий; нормализация, разбор строки, объединение; `shopping_list_service`, теги, запись событий и SSE-хаб; `create-user` | выполнен |
| 3 | [REST API и вход в PWA](2026-09-30-03-rest-api-and-sessions.md) | Cookie-сессии, логин с ограничением попыток, эндпоинты позиций и тегов, SSE, ошибки, экспорт OpenAPI | выполнен |
| 4 | [MCP-сервер и PAT](2026-10-01-04-mcp-and-pat.md) | `MCPServer` как resource server, верификатор PAT, middleware, инструменты, инструкции | выполнен |
| 5 | [Деплой и CD](2026-10-03-05-deploy-and-cd.md) | Dockerfile'ы, полный `docker-compose.yml`, Caddy, `images.yml`, `deploy.yml`, публичный HTTPS на sslip.io, подключение Claude Code по PAT | деплой выполнен; остаётся проверка Claude Code владельцем |
| 6 | [OAuth Authorization Server](2026-10-04-06-oauth.md) | Метаданные, CIMD и DCR, authorize, экран и API согласия, token с ротацией, revoke, подключённые приложения | развёрнут в v0.2.0; ручная приёмка реальных OAuth-клиентов впереди |
| 7 | [Интерфейс списка / PWA](2026-10-04-07-shopping-ui.md) | React, типизированный клиент, вход, список, карточка покупки, купленное, фильтры и живые обновления | список и редактор реализованы; настройки и установка PWA впереди |
| 8 | Push-уведомления | Подписки, outbox, воркер, VAPID, обработка push в service worker; приёмочный сценарий спеки §1 | — |

Порядок выбран так, чтобы рискованное проверялось рано: реальный деплой через прокси хостинга
(открытый вопрос спеки §13) — сразу после появления MCP, до объёмной работы над OAuth и PWA.

На 2026-10-04 `v0.4.0` развёрнут на https://grocery.94-159-101-162.sslip.io.
Владелец подтвердил работу интерфейса и регистрации. В `v0.4.0` добавлена карточка
редактирования покупки; её визуальная приёмка ещё предстоит. Полная проверка: 604 backend-
и 13 UI-тестов. Внешние проверки редактирования, регистрации, cookie-входа, операций списка,
PAT, MCP SDK и SSE через Caddy прошли. Cloudflare в текущей схеме нет.

Этап 6 реализован в коде; минимальный экран входа и согласия перенесён сюда из этапа 7.
До приёмки нужна ручная проверка браузера и реальных MCP-клиентов.
В этапе 7 реализован минимальный интерфейс списка для телефона и браузера ноутбука.
